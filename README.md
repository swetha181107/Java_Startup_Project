# KEC Student Innovation & Startup Seed Grant Allocator

Java and MySQL project for managing startup grant applications.

## Features
- Import startup proposals from CSV.
- Evaluate proposals using parallel processing.
- Calculate scores and allocate grants.
- View startup rankings.
- Generate sanction letters.
- Calculate ISM.

## Requirements
- JDK 21
- MySQL 8
- MySQL Connector/J

## How to Run
1. Configure database settings in config/db.properties.
2. Run build.bat.
3. Run run.bat.
